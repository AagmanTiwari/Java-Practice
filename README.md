## 💻 How to Run Java Programs

### Prerequisites

Install **JDK 17 or later** and verify the installation:

```bash
java -version
javac -version
```

### Step 1: Clone the Repository

```bash
git clone https://github.com/AagmanTiwari/java-practice.git
```

### Step 2: Navigate to the Repository

```bash
cd java-practice
```

### Step 3: Compile a Java Program

Navigate to the folder containing the Java file.

For a Java program without a package declaration:

```bash
javac ProgramName.java
```

### Step 4: Execute the Program

```bash
java ProgramName
```

Replace `ProgramName` with the actual Java class name.

**Note:** For programs using Java packages, compile from the appropriate source root and execute using the fully qualified class name.
